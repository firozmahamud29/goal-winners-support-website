# Goal Winners Support — Website Concept

A responsive, Elementor-ready visual prototype for Goal Winners Support. This is a design concept for client review, not a production WordPress installation.

## Preview

The project is designed to publish as a static GitHub Pages concept until the client selects WordPress hosting. The final implementation should be rebuilt in WordPress using the Hello Elementor theme and Elementor.

## Design direction

- Calm, respectful, care-focused visual language
- Navy and teal palette drawn from the approved requirements questionnaire
- Clear paths for individuals, families, and service coordinators
- Original provisional copy; all service, partner, contact, and compliance claims require client approval
- No public collection of medical, diagnosis, or disability-sensitive information
- Roommate matching is presented as a possible future feature, not an implemented system

## Elementor mapping

| Prototype area | Elementor implementation |
| --- | --- |
| Header | Theme Builder Header + Site Logo + Nav Menu + Button |
| Hero | Container with Heading, Text Editor, Buttons, and Image/illustration |
| Trust strip | Inner Container with four Icon List or Text widgets |
| Services | Three-column Container with Icon Box widgets |
| Our approach | Two-column Container with Image/Shape + Heading + Icon List |
| Referral process | Three-column Container with numbered Icon Boxes |
| Audience paths | Three linked Call to Action cards |
| FAQ | Accordion widget |
| Contact | Two-column Container with copy and Form widget |
| Footer | Theme Builder Footer with Site Logo, text, buttons, and legal links |

## Responsive behavior

- Desktop: two-column hero and approach sections, three-column service/audience/process grids
- Tablet: reduced spacing and simplified navigation
- Mobile: stacked content, collapsed menu, full-width controls, large tap targets
- Keyboard focus states and reduced-motion support are included

## Before WordPress launch

Replace provisional values with approved:

- Logo and brand guidelines
- Final service copy
- Service areas
- Verified regional-center or partner statements
- Contact email and final phone number
- Approved photography and consent/release records
- Privacy policy and accessibility statement
- Form delivery and data-retention process

Do not connect a public form until the client approves the receiving email/service and privacy handling.
